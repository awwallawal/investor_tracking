# Story 1.1: Project Initialization & Health Check

## Status

Done

## Story

**As a** System Administrator,
**I want** the initial project structure, dependencies, and a basic health check endpoint to be created,
**so that** we have a verifiable, running application skeleton to build upon.

## Acceptance Criteria

1.  The project is initialized in two separate Git repositories (`oysipa-frontend`, `oysipa-backend`).
2.  The backend codebase is structured with a clear separation for routes, services, models, and middleware.
3.  The backend service can be started and exposes a `/health` endpoint that returns a `200 OK` status.
4.  The frontend application can be started and displays a simple placeholder page (e.g., "Welcome to OYSIPA Investor Tracker").

## Tasks / Subtasks

- [x] **Backend Setup (oysipa-backend)**
    - [x] Initialize a new Node.js project (`npm init -y`).
    - [x] Install core dependencies: `express`, `mongoose`, `cors`, `dotenv`, `jsonwebtoken`, `bcryptjs`.
    - [x] Install dev dependencies: `jest`, `supertest`, `nodemon`.
    - [x] Create the initial directory structure: `src/api`, `src/config`, `src/models`, `src/services`.
    - [x] Create the main server entry point (`server.js` or `index.js`).
    - [x] Implement a `/health` route in a `health.router.js` file that returns `{ status: 'UP' }` with a 200 OK.
    - [x] Create a basic Jest test for the `/health` endpoint to verify a 200 response.
- [x] **Frontend Setup (oysipa-frontend)**
    - [x] Initialize a new React project using Vite (`npm create vite@latest . -- --template react`).
    - [x] Install core dependencies: `react-router-dom`, `axios`, `@mui/material`, `@emotion/react`, `@emotion/styled`, `zustand`.
    - [x] Install dev dependencies: `vitest`, `@testing-library/react`, `jsdom`.
    - [x] Clear the default Vite template content from `App.jsx`.
    - [x] Create a simple placeholder component that displays "Welcome to OYSIPA Investor Tracker".
    - [x] Render the placeholder component in `App.jsx`.

## Dev Notes

- **Repository Structure:** This story establishes the foundation of our poly-repo structure. All backend code goes in `oysipa-backend`, and all frontend code in `oysipa-frontend`. [Source: architecture/2-high-level-architecture.md]
- **Tech Stack:** Adhere strictly to the versions and technologies defined in the Tech Stack table. For the backend, use Express.js with Mongoose. For the frontend, use React with Vite. [Source: architecture/3-tech-stack.md]
- **Testing:** This story includes the first tests for the project. The backend health check should have an API integration test, and the frontend should have a simple component render test. [Source: architecture/3-tech-stack.md]
