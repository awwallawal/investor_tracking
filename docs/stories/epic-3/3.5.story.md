## Story

**As a** Staff Member,
**I want** to upload a document when I log an interaction,
**so that** I can attach supporting evidence like a scanned letter.

## Acceptance Criteria

1.  The "Log a New Interaction" form includes a file input field.
2.  The user can select a file (e.g., PDF, DOCX, JPG).
3.  Upon form submission, the file is securely uploaded to the designated file storage (Cloudinary).
4.  The URL of the uploaded file is saved with the interaction log record.
5.  The interaction log display shows a link to view or download the attached document.

## Dev Notes

- **Data Models**: 
    - **Model: InteractionLog** [Source: architecture/4-data-models.md]
        - Key Attributes: `documentUrl`: `String` - An optional URL pointing to a supporting document stored in Cloudinary.

- **API Specifications**: 
    - `POST /projects/{projectId}/interactions`: Create a new interaction log. [Source: architecture/5-api-specification.md]
        - Request Body: `InteractionLogRequest` (includes `documentUrl`).

- **File Storage:** Cloudinary [Source: architecture/3-tech-stack.md]
    - A robust, managed service for file uploads, transformations, and delivery.
