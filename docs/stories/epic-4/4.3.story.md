## Story

**As the** Director-General,
**I want** to be able to click on elements of my dashboard to see the underlying data,
**so that** I can investigate interesting metrics without having to manually search for the information.

## Acceptance Criteria

1.  The KPI widgets on the DG dashboard are interactive.
2.  Clicking on a segment of the "projects by lifecycle stage" chart navigates to a pre-filtered list showing all the projects currently in that stage.
3.  Clicking on the "total investors" widget navigates to the full Investor Directory.

## Dev Notes

- **Frontend Routing**: This story heavily involves frontend routing and state management. The `useNavigate` and `useSearchParams` hooks from `react-router-dom` will be essential.

- **Component Reusability**: The goal is to make the dashboard widgets interactive without tightly coupling them to specific pages. Passing navigation paths as props is the recommended approach.

- **API Filtering**: The backend project-fetching logic will need to be updated to handle query parameters. The controller for `GET /api/projects` should be checked and modified to include a `find` query filter if a `lifecycleStage` parameter is present in `req.query`.

- **File Locations**:
    - **Frontend Pages**: `oysipa-frontend/src/pages/DGDashboard.jsx`, `oysipa-frontend/src/pages/InvestorDirectoryPage.jsx`, and potentially a new `oysipa-frontend/src/pages/ProjectListPage.jsx`.
    - **Frontend Components**: `oysipa-frontend/src/components/KpiWidget.jsx`, `oysipa-frontend/src/components/LifecycleChart.jsx`.
    - **Backend Controller**: The existing controller that handles `GET /api/projects` will need modification.

- **Testing**:
    - Focus on testing the navigation logic in the frontend components.
    - For the backend, focus on testing the filtering logic in the controller.
