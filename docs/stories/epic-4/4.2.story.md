## Story

**As the** Director-General,
**I want** to see a high-level dashboard with key performance indicators (KPIs) for the entire agency,
**so that** I can have a quick, strategic overview of all investment promotion activities.

## Acceptance Criteria

1.  The default landing page after the Director-General logs in is the high-level oversight dashboard.
2.  The dashboard displays several KPI widgets, including at a minimum:
    *   A count of the total number of investors.
    *   A count of the total number of active projects.
    *   A chart or summary showing the number of projects in each lifecycle stage.
    *   A count of total support interactions logged across the agency in the last 30 days.

## Dev Notes

- **Data Models**:
    - **User**: The user's role will be checked on the backend to authorize access to the KPI endpoint. The frontend will use the role from the JWT to determine which dashboard to render. [Source: `docs/architecture/4-data-models.md`]
    - **Investor**: The backend will need to perform a `countDocuments()` query on the `investors` collection. [Source: `docs/architecture/4-data-models.md`]
    - **InvestmentProject**: The backend will need to perform a `countDocuments()` query and an aggregation query (`$group`) to count projects by `lifecycleStage`. [Source: `docs/architecture/4-data-models.md`]
    - **InteractionLog**: The backend will need to perform a `countDocuments()` query with a date range filter on the `createdAt` field. [Source: `docs/architecture/4-data-models.md`]

- **API Specifications**:
    - A new route `GET /api/admin/dashboard-kpis` will be created.
    - Access will be restricted to the 'Director-General' role. A new middleware function might be needed for this.
    - The response should be a single JSON object containing all the calculated KPIs.

- **File Locations**:
    - **Backend Route**: A new file `oysipa-backend/src/api/admin.js` should be created.
    - **Backend Controller**: A new file `oysipa-backend/src/controllers/adminController.js` should be created.
    - **Frontend Page**: `oysipa-frontend/src/pages/DGDashboard.jsx`.
    - **Frontend Components**: `oysipa-frontend/src/components/KpiWidget.jsx`, `oysipa-frontend/src/components/LifecycleChart.jsx`.

- **Testing**:
    - Backend tests will use Jest and Supertest. [Source: `docs/architecture/coding-standards.md`]
    - Frontend tests will use Vitest and React Testing Library. [Source: `docs/architecture/coding-standards.md`]
