# Story 2.6: UI Polish: Apply Design System to Core Components

## Status

Done

## Story

**As a** User,
**I want** the application's core interface elements (from Epic 1) to reflect the defined design system,
**so that** the application has a professional and consistent visual appearance.

## Acceptance Criteria

1.  All core components from Epic 1 (Login, Dashboard placeholder, User Management page, Header, Sidebar, Logout Button) reflect the specified color palette from `front-end-spec.md`.
2.  All text elements in Epic 1 components use the defined typography (font family, sizes, weights) from `front-end-spec.md`.
3.  Basic Material-UI component styling (e.g., button variants, form input appearance) is consistently applied according to the `front-end-spec.md`.
4.  No new functional changes or UI elements are introduced.

## Tasks / Subtasks

- [x] **Frontend (oysipa-frontend)**
    - [x] Review `front-end-spec.md` (Color Palette, Typography, Core Components sections) and `architecture.md` (Tech Stack - MUI `sx` prop).
    - [x] Apply primary and secondary colors to relevant UI elements (e.g., backgrounds, headers, buttons).
    - [x] Ensure all text uses the 'Poppins' font family with specified sizes and weights.
    - [x] Verify Material-UI components (Buttons, Form Inputs) use appropriate variants and styling as per the spec.

## Dev Notes

- **Styling Approach:** Strictly use Material-UI's `sx` prop for component-level styling. Avoid external CSS files.
- **Scope:** This story is purely for visual polish. Do NOT introduce any new functionality, UI elements, or layout changes beyond what is necessary to apply the design system.
- **Reference:** Refer to `front-end-spec.md` for detailed design guidelines and `architecture.md` for the chosen styling approach.

## Testing Guidance

- **Visual Inspection:**
    - Verify that colors match the specified palette.
    - Confirm font families, sizes, and weights are correct.
    - Check consistency of button and form input styling.
- **No Functional Regression:** Ensure existing functionality of Epic 1 components remains unchanged.
