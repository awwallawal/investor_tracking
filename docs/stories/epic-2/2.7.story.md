## Dev Notes

- **Testing Requirements:** Use Vitest and React Testing Library (RTL). Tests should focus on simulating user behavior and component functionality, not implementation details.
- **File Locations:** Test files should be co-located with the components they test (e.g., `oysipa-frontend/src/pages/Login.test.jsx`, `oysipa-frontend/src/pages/UserManagementPage.test.jsx`). [Source: architecture/source-tree.md]
- **Component Specifications:** Refer to `front-end-spec.md` for UI details and expected component behavior.
- **Technical Constraints:** Ensure tests run within the existing frontend test environment (`oysipa-frontend/package.json`).

## Testing Guidance

- **Unit Tests:** Focus on isolated component behavior.
- **Integration Tests:** Consider if any interactions between components (e.g., Login form submission leading to dashboard redirect) warrant integration tests.
